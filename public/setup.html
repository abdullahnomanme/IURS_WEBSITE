First-time IURS Admin Setup

Create the first executive/admin account. This page only works while the database has no user accounts and can be completed without a setup token. If you later add a SETUP_TOKEN secret in Cloudflare, enter it here for an extra protection layer.

After the first account is created, this endpoint permanently closes the initial setup path until the database is reset.

Keep the setup token private. Once the first account exists, this page cannot create another account.
